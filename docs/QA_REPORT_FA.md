# گزارش کنترل کیفیت پروژه

## اصلاحات پایداری و امنیتی

- اصلاح کامل `RoleSessionAuth`: اجرای سازندهٔ `SessionAuth` و امضای صحیح `authenticate(request, key)`
- افزودن System Check اختصاصی برای جلوگیری از بازگشت خطای `csrf`
- استانداردسازی تمام پاسخ‌های چندحالته Django Ninja و کنترل Schemaهای 4xx
- جلوگیری از افشای وجود شماره سفارش متعلق به کاربر دیگر
- پرداخت idempotent و ترمیم خودکار Payment ناقص یا مبلغ ناسازگار
- جلوگیری از پرداخت دو سفارش معلق برای یک دورهٔ یکسان
- قفل‌کردن Coupon هنگام پرداخت برای رعایت محدودیت کلی و هر کاربر
- محافظت مدیر از غیرفعال‌کردن یا کاهش نقش خودش و محافظت Superuser
- اعتبارسنجی طول نام، ایمیل، رمز، پیام تماس، نظر و اطلاعات Checkout
- افزایش فضای تصادفی شماره سفارش

## کنترل‌های مستقل اجراشده در محیط ساخت

فرمان زیر با موفقیت اجرا شده است:

```bash
python scripts/preflight.py
```

این فرمان موارد زیر را کنترل می‌کند:

- نحو تمام فایل‌های Python و ۷۱ تست نوشته‌شده
- نحو ۸ فایل JavaScript با `node --check`
- وجود فایل‌های ضروری پروژه
- صحت تمام نام‌های `{% url %}` در Templateها
- وجود تمام فایل‌های `{% static %}`
- نبود `id` تکراری داخل هر Template
- تطبیق ۱۳ فراخوانی API فرانت با Routeهای Django Ninja
- وجود Response Schema برای هر endpoint دارای `Status(...)`
- اجرای `super().__init__()` و امضای صحیح `RoleSessionAuth`
- `PRAGMA integrity_check` و `PRAGMA foreign_key_check` روی SQLite
- سازگاری مبلغ سفارش، پرداخت موفق و Enrollment فعال
- نبود مسیر مطلق وابسته به کامپیوتر سازنده در سورس
- صحت نحوی اسکریپت‌های Shell

## مجموعه تست Runtime

در پنج app مجموعاً **۷۱ تست** نوشته شده است:

| بخش | تعداد تست |
|---|---:|
| Accounts و دسترسی‌ها | ۱۹ |
| Catalog، علاقه‌مندی و Review | ۱۲ |
| Cart، Order، Coupon و Payment | ۱۸ |
| Dashboard و نقش مدیر | ۱۳ |
| صفحات عمومی، تماس و خبرنامه | ۹ |

سناریوها شامل ثبت‌نام و ورود، Session و CSRF واقعی، 401/403، تمام صفحه‌ها، Swagger، جست‌وجو و فیلتر، سبد، Checkout، پرداخت، مالکیت سفارش، Snapshot، خرید تکراری، Coupon، Review، پیام تماس و عملیات مدیریتی هستند.

## اجرای کامل روی سیستم پروژه

از ریشه پروژه و با interpreter همان پروژه اجرا شود:

```bash
cd <PROJECT_ROOT>
source .venv/bin/activate
PYTHON_BIN=.venv/bin/python ./scripts/qa_all.sh
```

این دستور به‌ترتیب اجرا می‌کند:

```text
preflight
manage.py check
makemigrations --check --dry-run
71 Django tests
```

## محدودیت محیط ساخت

محیط ساخت به نصب بسته‌های Python از شبکه دسترسی نداشت؛ بنابراین اجرای خود `manage.py test` در این محیط ممکن نبود. با این حال، تمام ۷۱ تست از نظر نحو Compile شده‌اند و کنترل‌های مستقل بالا واقعاً اجرا و موفق شده‌اند. اسکریپت `qa_all.sh` برای اجرای Runtime روی محیط محلی پروژه اضافه شده است.
